# 👑 Kajal & Anmol — Royal Wedding Invitation

A mobile-first, interactive royal Indian wedding invitation website designed with bilingual English & Kannada typography, 60fps cinematic haveli door entrance, gold-foil scratch cards, live countdown timer, interactive couple gallery, wedding soundtrack, and instant WhatsApp RSVP.

---

## ✨ Features

- **Cinematic 60fps Haveli Gate Entrance:** Tap to swing open carved wooden doors and enter the courtyard.
- **Bilingual English & Kannada Support:** Instant 1-tap language switch (`English` ⇄ `ಕನ್ನಡ`).
- **Sacred Invocation:** Framed royal dome with *॥ Sri Ganeshaya Namaha ॥* / *॥ ಶ್ರೀ ಗಣೇಶಾಯ ನಮಃ ॥*.
- **Gold Foil Scratch-to-Reveal:** Scratch cards for Day (18), Month (December), and Year (2026).
- **Live Countdown Timer:** Real-time countdown to the celebrations with zero-overlap responsive layout.
- **Couple Moments Gallery:** Royal arch carousel showcasing cherished moments.
- **Wedding Song Player:** Integrated Spotify player for *"Jodi Jodi"* from *Ramayana*.
- **1-Tap Navigation & Google Calendar:** Direct Google Maps navigation to Veerashaiva Kalyana Mantap, Alnavar.
- **Zero-Backend WhatsApp RSVP:** Guests confirm attendance and guest counts directly to WhatsApp.

---

## 🛠️ Tech Stack

- Pure Static Web Application (HTML5, CSS3, ES6+ JavaScript, SVG)
- Google Fonts: *Noto Serif Kannada*, *Anek Kannada*, *Cormorant Garamond*, *Pinyon Script*
- 100% self-contained: No backend database or server required.

---

## 🚀 Deployment

Host for free on **GitHub Pages**:
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch**, branch **main**, folder **/(root)**.
4. Click **Save** — your wedding invitation will be live in seconds!
